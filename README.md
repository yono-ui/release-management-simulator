# Release Management Simulator

Minimal scaffold: React + Vite frontend-only project for an academic Release Management Simulator (Configuration Management).

What’s included

- React + Vite (JavaScript)
- Project structure:
  - src/
    - components/
    - pages/
    - data/
    - utils/
    - styles/
- Basic working app that displays sample data.

Run locally

1. npm install
2. npm run dev

Notes

- No backend, database, or external APIs.
- Local React state and localStorage utilities are prepared for later work.
- I will continue building features once you confirm the next tasks.
